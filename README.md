# Jira Timeline Weekend Marker

Jira Cloud 타임라인(주 단위 보기)에서 **토·일요일과 한국 공휴일 열**을 빨갛게 강조하거나 화면에서 가려 주는 Chrome 확장 프로그램입니다.

## 설치 (개발자 모드)

1. `chrome://extensions` 를 열고 우측 상단 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드** → 이 폴더(`jira-weekend-marker`)를 선택합니다.
3. Jira 타임라인 페이지를 새로고침하면 바로 적용됩니다.

## 사용

툴바의 확장 아이콘을 눌러 설정합니다. 저장은 자동이며 열려 있는 Jira 탭에 즉시 반영됩니다.

| 설정 | 설명 |
|---|---|
| 빨갛게 강조 | 주말 열에 붉은 음영, 공휴일 열은 빗금 음영. 헤더 날짜 숫자도 빨간색(공휴일은 점선 밑줄). 숫자에 마우스를 올리면 휴일 이름이 표시됩니다. |
| 화면에서 가리기 | 주말/공휴일 열의 배경과 날짜 숫자를 지워 보이지 않게 합니다. 레이아웃은 그대로 유지됩니다. |
| 끄기 | 아무것도 표시하지 않습니다. |
| 한국 공휴일 포함 | 내장된 2025~2027 법정 공휴일·대체공휴일 목록을 사용합니다. |
| 이슈 막대 위까지 덮기 | 켜면 주말/공휴일 구간의 이슈 막대까지 음영으로 덮습니다. |
| 사용자 지정 휴일 | `YYYY-MM-DD 이름` 형식으로 한 줄에 하나씩. 회사 창립기념일, 워크숍 등. |

## 동작 원리 / 제한 사항

- 헤더의 요일 셀(`calendar-cells.week.day-0..6`)과 "Today is …" 표시를 기준으로 각 셀의 실제 날짜를 계산한 뒤,
  각 행의 주 단위 컬럼 오버레이(`columns-overlay.column-N`) 안에 1/7 폭의 음영을 삽입합니다.
- Jira 가 React 로 재렌더링해도 MutationObserver 가 감지해 다시 적용합니다.
- **주(week) 단위 보기에서만** 동작합니다. 월/분기 보기는 요일 셀이 없어 표시할 대상이 없습니다.
- 열을 실제로 접어 없애지는 않습니다(막대 위치가 픽셀로 고정되어 있어 접으면 Jira 와 충돌).
- Jira 의 DOM 구조가 바뀌면 `content.js` 상단의 `DAY_PREFIX`, `COL_PREFIX` 만 수정하면 됩니다.

## 공휴일 데이터

`holidays.js` 에 2025~2027 목록이 있습니다. 2026-04-30 규정 개정으로 추가된 노동절(5/1)·제헌절(7/17)이 반영되어 있습니다.
2028년 이후는 파일에 같은 형식으로 추가하거나 팝업의 사용자 지정 휴일에 입력하세요.
