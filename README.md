# Jira Timeline Weekend Marker

A browser extension for the Jira Cloud timeline (Weeks view) that **highlights or hides weekend and public-holiday columns**, shows the **number of working days** inside every issue bar and **warns about deadlines** that are overdue or close.
Holiday calendars for South Korea, the United States, China and India; UI in Korean, English, Chinese and Hindi.

[한국어 설명은 아래에 있습니다 ↓](#jira-timeline-weekend-marker-한국어)

## Features

**Weekend / holiday columns**

- **Highlight** – weekend columns get a colored tint (red by default), public holidays a hatched tint, and the day numbers in the timeline header are colored (holidays dotted-underlined). Hover a day number to see the holiday name.
- **Mask** – weekend/holiday columns are blanked out with the page background so the timeline reads as working days only. Nothing is removed from the DOM and the layout is untouched, so Jira keeps working normally.
- **Cover issue bars too** – by default the shading sits *under* the issue bars. With this option on, a per-row shading layer is drawn *over* the bars (in Mask mode the bars are visually cut at weekends). Row separators and the sticky left columns are not affected. In this mode the empty area below the last row is not shaded.
- **Off** – disables everything, including the badges below.

**Issue bars**

- **Working-day count** – every issue bar gets a badge with the number of working days between its start and due date (inclusive), excluding weekends and the selected country's public holidays. China's adjusted working weekends (调休) count as working days. Dates are read from the bar's accessibility label (`YYYY/MM/DD`); if that is unavailable the dates are derived from the bar's pixel position. On bars narrower than 56 px the badge is placed to the right of the bar. Badges update immediately when a bar is dragged or resized.
- **Deadline warning** – an issue that is **overdue** or **due within N working days** (N adjustable, default 3; the due date itself counts as 0 days left) gets a warning icon in the badge and a thin outline around the bar (dark yellow by default). Resolved issues (struck-through issue key) are skipped. Hover the icon for "overdue by N days" / "N working days left".

**Calendar**

- **Countries** – South Korea (KR), United States (US), China (CN), India (IN). The default is detected from the browser language (`ko`→KR, `zh`→CN, `hi` or any `*-IN` locale→IN, anything else or unknown→US) and can be changed in the popup. Weekends are Saturday and Sunday for all four countries.
- **Holiday data through 2028** – KR statutory holidays incl. substitute holidays, the 2026 additions (Labor Day 5/1, Constitution Day 7/17) and the 2028 general election day; US federal holidays generated by rule (observed-day shifting included); CN State Council schedules for 2025–2026 incl. adjusted working weekends (shown with a dashed underline in the header and never shaded), 2027–2028 provisional; IN DoPT gazetted holidays for 2025–2026, 2027–2028 provisional.
- **Custom days off** – add company holidays as `YYYY-MM-DD name`, one per line. They are treated like public holidays (shading, badge count, deadline warning).

**Appearance & language**

- **Languages** – the popup and all tooltips follow the selected country's language (ko / en / zh / hi); the language can be overridden independently. The store listing is localized as well.
- **Colors** – highlight color, shading intensity (5–60 %) and warning color are adjustable, with a *Reset colors* button.
- **Update notice** – after the extension is updated, the toolbar icon shows a "NEW" badge and the popup shows an "Updated to vX — see what's new" link to the release notes until it has been opened once.
- Settings are stored with `storage.sync`, so Chrome/Edge sync them across devices signed in to the same browser profile (Safari keeps them local).

## Install

### Chrome / Edge (Windows, macOS, Linux)

1. Download `jira-weekend-marker-<version>-chrome-edge.zip` from the [Releases](../../releases) page and unzip it.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.
4. Reload your Jira timeline page.

The same package works in every Chromium-based browser; no manifest changes are needed for Edge.

### Safari (macOS)

Safari uses the same WebExtension code but requires the extension to be wrapped in a native macOS app with Xcode.

1. Download `jira-weekend-marker-<version>-safari-source.zip` and unzip it (or use this repository).
2. Run `./safari/build-safari.sh` (requires Xcode). It calls `xcrun safari-web-extension-converter`, creates an Xcode project under `safari/build/` and normalises the bundle identifiers.
3. Open the project in Xcode and press **Run**. The extension then appears in **Safari ▸ Settings ▸ Extensions**.
4. If you did not sign the app, enable **Develop ▸ Allow Unsigned Extensions** in Safari first (Develop menu: Settings ▸ Advanced ▸ *Show features for web developers*).
5. Safari asks for permission for `atlassian.net` the first time you open Jira — allow it.

A pre-built, unsigned `jira-weekend-marker-<version>-safari-macos-app.zip` is attached to releases when the macOS CI job succeeds.

## Usage

Click the toolbar icon to open the popup. Settings are saved automatically and applied to open Jira tabs immediately. The bottom line of the popup reports what was detected on the current tab (number of weeks, anchor date) or why nothing is shown (not a Jira tab, timeline not found, not in Weeks view).

| Setting | Description |
|---|---|
| Country | Auto (browser language) or KR / US / CN / IN. Determines the holiday calendar and the default language. |
| Language | Auto (follows country) or English / 한국어 / 中文 / हिन्दी. |
| Highlight (colored) | Tint on weekends, hatched tint on public holidays, colored day numbers. |
| Hide from timeline (mask) | Blank out weekend/holiday columns. |
| Off | Disable everything. |
| Include public holidays | Use the built-in holiday calendar for the selected country (weekends are always marked). |
| Cover issue bars too | Draw the shading above the issue bars (per-row layer). |
| Show working-day count in bars | Badge with the working days of each issue bar. |
| Deadline warning · within N working days | Warning icon + outline on bars that are overdue or due within N working days (N = 0–60). |
| Highlight color / Intensity / Warning color | Colors and shading opacity; *Reset colors* restores the defaults. |
| Custom days off | `YYYY-MM-DD name`, one per line. |

## How it works / limitations

- The content script reads the day cells in the timeline header (`calendar-cells.week.day-0..6`) and the `Today is …` marker (or, failing that, a month label such as `Sep '25`) to compute the real date of every cell.
- Shading is inserted as 1/7-width elements into Jira's week column overlays (`columns-overlay.column-N`); in cover mode an additional per-row layer with a single `linear-gradient` is placed inside each issue row above the bars.
- Issue bars are located by their `draggable-bar-…-container` test id; badges are appended inside the bar container. Resolved issues are detected by the strike-through on the issue-key link, independent of the UI language.
- Jira re-renders the timeline constantly (React); a `MutationObserver` re-applies everything idempotently, and an attribute observer on the bars reacts to drag/resize.
- Works only in the **Weeks** zoom level. Months/Quarters views have no day cells, so nothing is displayed there (the popup tells you so).
- Columns are not physically collapsed – Jira positions bars in fixed pixels, so collapsing columns would fight the app.
- If Atlassian changes the DOM, the selectors at the top of `content.js` (`DAY_PREFIX`, `COL_PREFIX`, `BAR_SELECTOR`, `ROW_SELECTOR`, `KEY_LINK_SELECTOR`) are the only things that need updating.

## Holiday data

Holiday calendars live in `holidays.js` (per country: `dates`, `workdays`, optional rule-based `generate`); UI strings in `locales.js`. Dates that governments have not yet officially confirmed (CN 2027–2028 State Council notices, IN 2027–2028 DoPT lists, moon-sighting dependent Islamic holidays) are marked *provisional* in the holiday name — please verify against official announcements and adjust via *Custom days off* or a pull request.

## Security & privacy

The extension requests only `storage` and host access to `https://*.atlassian.net/jira/*`. It makes no network requests, collects no data and bundles all holiday tables. Injected elements are built with DOM APIs (no `innerHTML`) and every stored setting is validated before use. See [SECURITY.md](SECURITY.md) for details and for how to report a vulnerability.

# Jira Timeline Weekend Marker (한국어)

Jira Cloud 타임라인(주 단위 보기)에서 **주말·공휴일 열을 강조하거나 가리고**, 이슈 막대마다 **근무일 수**를 표시하며, 기한이 지났거나 임박한 이슈에 **마감 경고**를 표시하는 브라우저 확장 프로그램입니다.
대한민국·미국·중국·인도 공휴일을 지원하며 UI는 한국어·영어·중국어·힌디어로 제공됩니다.

## 기능

**주말·공휴일 열**

- **강조** – 주말 열은 색 음영(기본 빨강), 공휴일 열은 빗금 음영으로 표시하고 헤더의 날짜 숫자도 같은 색(공휴일은 점선 밑줄)으로 바꿉니다. 숫자에 마우스를 올리면 휴일 이름이 표시됩니다.
- **마스킹** – 주말/공휴일 열을 페이지 배경색으로 덮어 근무일만 보이게 합니다. DOM을 지우거나 레이아웃을 바꾸지 않으므로 Jira 동작에 영향이 없습니다.
- **이슈 막대 위까지 덮기** – 기본적으로 음영은 막대 *아래*에 깔립니다. 이 옵션을 켜면 각 이슈 행 안에 행 전용 음영 층을 만들어 막대 *위*에 그립니다(마스킹 모드에서는 막대가 주말 구간에서 잘려 보임). 행 구분선과 왼쪽 고정 열에는 영향을 주지 않으며, 이 모드에서는 마지막 행 아래 빈 영역은 칠하지 않습니다.
- **끄기** – 아래 배지를 포함해 모든 표시를 끕니다.

**이슈 막대**

- **근무일 수 표시** – 모든 이슈 막대에 시작일~기한(양끝 포함) 사이의 근무일 수를 배지로 표시합니다. 주말과 선택한 국가의 공휴일은 제외하고, 중국의 조휴(调休) 근무일은 근무일로 셉니다. 날짜는 막대의 접근성 라벨(`YYYY/MM/DD`)에서 읽고, 없으면 막대의 픽셀 위치로 역산합니다. 폭이 56px 미만인 막대는 배지를 막대 오른쪽 바깥에 둡니다. 막대를 드래그하거나 늘리면 즉시 다시 계산됩니다.
- **마감 경고** – 기한이 **지났거나** **N 근무일 이내**인 이슈(N 조절 가능, 기본 3일, 기한 당일은 0일 남음)에 배지 경고 아이콘과 막대 둘레의 얇은 테두리(기본 짙은 노란색)를 표시합니다. 완료된 이슈(이슈 키에 취소선)는 제외합니다. 아이콘에 마우스를 올리면 "기한이 N일 지났습니다" / "근무일 N일 남음"이 표시됩니다.

**달력**

- **국가** – 대한민국(KR), 미국(US), 중국(CN), 인도(IN). 기본값은 브라우저 언어로 자동 결정되며(`ko`→KR, `zh`→CN, `hi` 또는 `*-IN` 로케일→IN, 그 외 또는 판별 불가→US) 팝업에서 바꿀 수 있습니다. 네 나라 모두 주말은 토·일요일입니다.
- **2028년까지의 공휴일 데이터** – 한국은 대체공휴일, 2026년 신설된 노동절(5/1)·제헌절(7/17), 2028년 국회의원 선거일 포함. 미국 연방 공휴일은 규칙으로 자동 계산(관측일 이동 포함). 중국은 2025~2026 국무원 공지의 조휴 근무일(헤더에 점선 밑줄, 음영 없음)까지 반영하고 2027~2028은 잠정. 인도는 2025~2026 DoPT 관보 휴일, 2027~2028은 잠정.
- **사용자 지정 휴일** – `YYYY-MM-DD 이름` 형식으로 한 줄에 하나씩 회사 휴일을 추가하면 공휴일과 동일하게(음영, 근무일 계산, 마감 경고) 처리됩니다.

**모양·언어**

- **언어** – 팝업과 모든 툴팁은 선택한 국가의 언어(ko / en / zh / hi)를 따르며 언어만 따로 바꿀 수도 있습니다. 스토어 설명도 다국어입니다.
- **색상** – 강조 색상, 음영 강도(5~60%), 경고 색상을 조절할 수 있고 *색상 초기화* 버튼으로 기본값으로 돌아갑니다.
- **업데이트 알림** – 확장이 업데이트되면 툴바 아이콘에 "NEW" 배지가 붙고, 팝업에 "vX로 업데이트됨 — 변경 내용 보기" 링크가 한 번 열 때까지 표시됩니다.
- 설정은 `storage.sync`에 저장되어 같은 브라우저 프로필로 로그인한 기기 간에 동기화됩니다(Safari는 로컬 저장).

## 설치

### Chrome / Edge (Windows, macOS, Linux)

1. [Releases](../../releases)에서 `jira-weekend-marker-<version>-chrome-edge.zip`을 받아 압축을 풉니다.
2. `chrome://extensions`(또는 `edge://extensions`)에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 눌러 폴더를 선택합니다.
4. Jira 타임라인 페이지를 새로고침합니다.

Chromium 계열 브라우저는 모두 같은 패키지를 사용하며, Edge용으로 manifest를 수정할 필요가 없습니다.

### Safari (macOS)

Safari는 같은 WebExtension 코드를 쓰지만, Xcode로 네이티브 macOS 앱에 감싸야 설치할 수 있습니다.

1. `jira-weekend-marker-<version>-safari-source.zip`을 받아 압축을 풀거나 이 저장소를 사용합니다.
2. `./safari/build-safari.sh`를 실행합니다(Xcode 필요). `xcrun safari-web-extension-converter`로 `safari/build/` 아래에 Xcode 프로젝트를 만들고 번들 ID를 정리합니다.
3. Xcode에서 프로젝트를 열고 **Run**을 누르면 **Safari ▸ 설정 ▸ 확장 프로그램**에 나타납니다.
4. 서명하지 않은 앱이라면 Safari의 **개발자용 ▸ 서명되지 않은 확장 프로그램 허용**을 먼저 켭니다(설정 ▸ 고급 ▸ *웹 개발자용 기능 표시*).
5. 처음 Jira를 열 때 Safari가 `atlassian.net` 접근 권한을 물어보면 허용합니다.

macOS CI 작업이 성공하면 서명되지 않은 `jira-weekend-marker-<version>-safari-macos-app.zip`이 릴리스에 첨부됩니다.

## 동작 원리 / 제한 사항

- 콘텐츠 스크립트가 타임라인 헤더의 요일 셀(`calendar-cells.week.day-0..6`)과 `Today is …` 표시(없으면 `Sep '25` 같은 월 라벨)를 읽어 각 셀의 실제 날짜를 계산합니다.
- 음영은 Jira의 주 단위 컬럼 오버레이(`columns-overlay.column-N`)에 1/7 폭 요소로 삽입하고, 덮기 모드에서는 각 이슈 행 안에 `linear-gradient` 하나로 그린 행 전용 층을 막대 위에 추가합니다.
- 이슈 막대는 `draggable-bar-…-container` 테스트 ID로 찾고 배지는 막대 컨테이너 안에 붙입니다. 완료된 이슈는 이슈 키 링크의 취소선으로 판별하므로 UI 언어와 무관합니다.
- Jira는 React로 수시로 재렌더링하지만 `MutationObserver`가 모든 표시를 멱등하게 다시 적용하고, 막대의 속성 변화(드래그·리사이즈)도 감지합니다.
- **주(Weeks) 단위 보기에서만** 동작합니다. 월/분기 보기에는 요일 셀이 없어 아무것도 표시되지 않으며 팝업에 그 사실이 표시됩니다.
- 열을 실제로 접지는 않습니다. Jira가 막대를 픽셀 단위로 배치하므로 열을 접으면 앱과 충돌합니다.
- Atlassian이 DOM을 바꾸면 `content.js` 상단의 선택자(`DAY_PREFIX`, `COL_PREFIX`, `BAR_SELECTOR`, `ROW_SELECTOR`, `KEY_LINK_SELECTOR`)만 수정하면 됩니다.

## 공휴일 데이터

공휴일 달력은 `holidays.js`(국가별 `dates`, `workdays`, 규칙 기반 `generate`), UI 문자열은 `locales.js`에 있습니다. 정부가 아직 공식 확정하지 않은 날짜(중국 2027~2028 국무원 공지, 인도 2027~2028 DoPT 목록, 달 관측에 따라 바뀌는 이슬람 명절)는 휴일 이름에 *잠정(暂定/अनुमानित)*으로 표시되어 있으니 공식 발표를 확인해 *사용자 지정 휴일*이나 Pull Request로 조정해 주세요.

## 보안·개인정보

확장이 요청하는 권한은 `storage`와 `https://*.atlassian.net/jira/*` 호스트 접근뿐입니다. 네트워크 요청을 전혀 하지 않고 데이터를 수집하지 않으며, 공휴일 표는 모두 내장되어 있습니다. 삽입 요소는 DOM API로만 생성하고(`innerHTML` 미사용) 저장된 설정값은 사용 전에 모두 검증합니다. 자세한 내용과 취약점 제보 방법은 [SECURITY.md](SECURITY.md)를 참고하세요.

## 프로젝트 구성

```
manifest.json        Manifest V3 (Chrome, Edge, Safari 공용)
SECURITY.md          권한, 데이터 처리, 취약점 제보
background.js        서비스 워커: 업데이트 후 "NEW" 배지
content.js / .css    타임라인 분석, 음영, 배지, 경고
holidays.js          공휴일 달력 (KR / US / CN / IN)
locales.js           UI 문자열 (en / ko / zh / hi), 국가 자동 판별
popup.html / .js     설정 팝업
_locales/            스토어용 다국어 이름·설명
safari/              Safari 변환 스크립트와 안내
test/                Jira 구조를 흉내 낸 픽스처로 돌리는 Playwright 회귀 테스트
build.sh             dist/*.zip 생성
.github/workflows/   릴리스 워크플로 (v* 태그 → GitHub Release)
```

## 개발

```
./build.sh                    # Chrome/Edge용 zip과 Safari 소스 패키지를 dist/에 생성
cd test && npm install && npm test   # 픽스처를 생성하고 모든 Playwright 검사를 실행
```

`v*` 태그를 푸시하면 `.github/workflows/release.yml` 워크플로가 릴리스를 생성하며, 릴리스 본문은 `CHANGELOG.md`의 해당 버전 섹션에서 가져옵니다.
