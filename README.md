# Jira Timeline Weekend Marker

A browser extension that **highlights or hides weekend and public-holiday columns** in the Jira Cloud timeline (Weeks view).
Supports South Korea, the United States, China and India, with the UI localized in Korean, English, Chinese and Hindi.

[한국어 설명은 아래에 있습니다 ↓](#jira-timeline-weekend-marker-한국어)

## Features

- **Highlight** – weekend columns get a red tint, public holidays a hatched red tint; the day numbers in the header turn red (holidays dotted-underlined). Hover a day number to see the holiday name.
- **Mask** – weekend/holiday columns are blanked out so the timeline reads as working days only. The layout is untouched, so nothing breaks in Jira.
- **Countries** – South Korea (KR), United States (US), China (CN), India (IN). The default is detected from the browser language (`ko`→KR, `zh`→CN, `hi`/`*-IN`→IN, anything else or unknown→US) and can be changed in the popup.
- **Languages** – the popup and tooltips follow the selected country's language (ko / en / zh / hi). You can override the language independently.
- **Holiday data through 2028** – KR statutory holidays incl. substitute holidays and the 2026 additions (Labor Day, Constitution Day); US federal holidays generated by rule; CN State Council schedules for 2025–2026 incl. adjusted working weekends (调休), 2027–2028 provisional; IN DoPT gazetted holidays for 2025–2026, 2027–2028 provisional.
- **Custom days off** – add company holidays as `YYYY-MM-DD name`, one per line.
- **Cover issue bars** – optionally draw the shading over the issue bars as well.
- **Working-day count** – every issue bar shows a badge with the number of working days between its start and due date (weekends and holidays excluded).
- **Due-date warning** – a bar whose due date falls on a weekend or holiday gets a warning icon and a thin dark-yellow outline.
- **Colors** – highlight color, shading intensity and warning color are adjustable.

## Install

### Chrome / Edge (Windows, macOS, Linux)

1. Download `jira-weekend-marker-<version>-chrome-edge.zip` from the [Releases](../../releases) page and unzip it.
2. Open `chrome://extensions` (or `edge://extensions`), turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.
4. Reload your Jira timeline page.

The same package works in every Chromium-based browser; no manifest changes are needed for Edge.

### Safari (macOS)

Safari uses the same WebExtension code but requires the extension to be wrapped in a native macOS app with Xcode.

1. Download `jira-weekend-marker-<version>-safari-source.zip` and unzip it (or use this repository).
2. Run `./safari/build-safari.sh` (requires Xcode). It calls `xcrun safari-web-extension-converter`, which creates an Xcode project under `safari/build/`.
3. Open the project in Xcode and press **Run**. The extension then appears in **Safari ▸ Settings ▸ Extensions**.
4. If you did not sign the app, enable **Develop ▸ Allow Unsigned Extensions** in Safari first (Develop menu: Settings ▸ Advanced ▸ *Show features for web developers*).
5. Safari asks for permission for `atlassian.net` the first time you open Jira — allow it.

A pre-built, unsigned `jira-weekend-marker-<version>-safari-macos-app.zip` is attached to releases when the macOS CI job succeeds.

## Usage

Click the toolbar icon to open the popup. Settings are saved automatically and applied to open Jira tabs immediately.

| Setting | Description |
|---|---|
| Country | Auto (browser language) or KR / US / CN / IN. Determines the holiday calendar and the default language. |
| Language | Auto (follows country) or English / 한국어 / 中文 / हिन्दी. |
| Highlight in red | Red tint on weekends, hatched tint on public holidays, red day numbers. |
| Hide from timeline (mask) | Blank out weekend/holiday columns. |
| Off | Disable. |
| Include public holidays | Use the built-in holiday calendar for the selected country. |
| Cover issue bars too | Draw the shading above the issue bars (Jira bars are `z-index: 3`). |
| Custom days off | `YYYY-MM-DD name`, one per line. |
| Show working-day count in bars | Badge with the working days of each issue bar. |
| Warn when the due date is a day off | Warning icon + outline on bars whose due date is a weekend/holiday. |
| Colors | Highlight color, intensity (5–60 %), warning color; *Reset colors* restores the defaults. |

## How it works / limitations

- The extension reads the day cells in the timeline header (`calendar-cells.week.day-0..6`) and the `Today is …` marker to compute the real date of every cell, then inserts 1/7-width shading elements into each row's week column overlay (`columns-overlay.column-N`).
- Jira re-renders the timeline constantly (React); a `MutationObserver` re-applies the shading idempotently.
- Works only in the **Weeks** zoom level. Months/Quarters views have no day cells.
- Columns are not physically collapsed – Jira positions bars in fixed pixels, so collapsing columns would fight the app.
- If Atlassian changes the DOM, only `DAY_PREFIX` / `COL_PREFIX` at the top of `content.js` need updating.

## Holiday data

Holiday calendars live in `holidays.js`; UI strings in `locales.js`. Dates that governments have not yet officially confirmed (CN 2027–2028 State Council notices, IN 2027–2028 DoPT lists, moon-sighting dependent Islamic holidays) are marked *provisional* in the holiday name — please verify against official announcements and adjust via *Custom days off* or a pull request.

## Development

```
./build.sh            # builds dist/*.zip for Chrome/Edge and the Safari source package
cd test && node make-fixture.js && node run.js   # Playwright regression test against a Jira-like fixture
```

Releases are produced by the GitHub Actions workflow in `.github/workflows/release.yml` when a `v*` tag is pushed.

# Jira Timeline Weekend Marker (한국어)

Jira Cloud 타임라인(주 단위 보기)에서 **주말·공휴일 열을 빨갛게 강조하거나 화면에서 가려 주는** 브라우저 확장 프로그램입니다.
대한민국·미국·중국·인도 공휴일을 지원하며, UI는 한국어·영어·중국어·힌디어로 제공됩니다.

## 기능

- **강조** – 주말 열은 붉은 음영, 공휴일 열은 붉은 빗금 음영으로 표시하고 헤더의 날짜 숫자를 빨갛게(공휴일은 점선 밑줄) 바꿉니다. 숫자에 마우스를 올리면 휴일 이름이 표시됩니다.
- **마스킹** – 주말/공휴일 열의 배경과 숫자를 지워 근무일만 보이게 합니다. 레이아웃은 그대로라 Jira 동작에 영향이 없습니다.
- **국가** – 대한민국(KR), 미국(US), 중국(CN), 인도(IN). 기본값은 브라우저 언어로 자동 결정되며(`ko`→KR, `zh`→CN, `hi`/`*-IN`→IN, 그 외 또는 판별 불가→US) 팝업에서 바꿀 수 있습니다.
- **언어** – 팝업과 툴팁은 선택한 국가의 언어(ko / en / zh / hi)를 따르며, 언어만 따로 바꿀 수도 있습니다.
- **2028년까지의 공휴일 데이터** – 한국은 대체공휴일과 2026년 신설된 노동절·제헌절 포함, 미국 연방 공휴일은 규칙으로 자동 계산, 중국은 2025~2026 국무원 공지(조휴 근무일 포함)와 2027~2028 잠정 일정, 인도는 2025~2026 DoPT 관보 휴일과 2027~2028 잠정 일정.
- **사용자 지정 휴일** – `YYYY-MM-DD 이름` 형식으로 회사 휴일을 추가할 수 있습니다.
- **막대 위까지 덮기** – 이슈 막대 위에도 음영을 그리는 옵션입니다.
- **근무일 수 표시** – 모든 이슈 막대에 시작일~기한 사이의 근무일 수(주말·공휴일 제외)를 배지로 표시합니다.
- **기한 경고** – 기한이 주말·공휴일인 막대에 경고 아이콘과 짙은 노란색 얇은 테두리를 표시합니다.
- **색상** – 강조 색상, 음영 강도, 경고 색상을 조절할 수 있습니다.

## 설치

### Chrome / Edge (Windows, macOS, Linux)

1. [Releases](../../releases)에서 `jira-weekend-marker-<version>-chrome-edge.zip`을 받아 압축을 풉니다.
2. `chrome://extensions`(또는 `edge://extensions`)에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 눌러 폴더를 선택합니다.
4. Jira 타임라인 페이지를 새로고침합니다.

Chromium 계열 브라우저는 모두 같은 패키지를 사용하며, Edge용으로 manifest를 수정할 필요가 없습니다.

### Safari (macOS)

Safari는 같은 WebExtension 코드를 쓰지만, Xcode로 네이티브 macOS 앱에 감싸야 설치할 수 있습니다.

1. `jira-weekend-marker-<version>-safari-source.zip`을 받아 압축을 풀거나 이 저장소를 사용합니다.
2. `./safari/build-safari.sh`를 실행합니다(Xcode 필요). `xcrun safari-web-extension-converter`가 `safari/build/` 아래에 Xcode 프로젝트를 만듭니다.
3. Xcode에서 프로젝트를 열고 **Run**을 누르면 **Safari ▸ 설정 ▸ 확장 프로그램**에 나타납니다.
4. 서명하지 않은 앱이라면 Safari의 **개발자용 ▸ 서명되지 않은 확장 프로그램 허용**을 먼저 켭니다(설정 ▸ 고급 ▸ *웹 개발자용 기능 표시*).
5. 처음 Jira를 열 때 Safari가 `atlassian.net` 접근 권한을 물어보면 허용합니다.

macOS CI 작업이 성공하면 서명되지 않은 `jira-weekend-marker-<version>-safari-macos-app.zip`이 릴리스에 첨부됩니다.

| 설정 | 설명 |

| 언어 | 자동(국가에 따름) 또는 English / 한국어 / 中文 / हिन्दी. |
| 빨갛게 강조 | 주말은 붉은 음영, 공휴일은 빗금 음영, 날짜 숫자는 빨간색. |
| 화면에서 가리기(마스킹) | 주말/공휴일 열을 지웁니다. |
| 끄기 | 비활성화. |
| 공휴일 포함 | 선택한 국가의 내장 공휴일 달력을 사용합니다. |
| 이슈 막대 위까지 덮기 | 이슈 막대 위에도 음영을 그립니다(Jira 막대는 `z-index: 3`). |
| 사용자 지정 휴일 | 한 줄에 하나씩 `YYYY-MM-DD 이름`. |
| 막대에 근무일 수 표시 | 각 이슈 막대의 근무일 수 배지. |
| 기한이 주말·공휴일이면 경고 | 기한이 휴일인 막대에 경고 아이콘 + 테두리. |
| 색상 | 강조 색상, 강도(5~60%), 경고 색상. *색상 초기화*로 기본값 복원. |

## 동작 원리 / 제한 사항

- 타임라인 헤더의 요일 셀(`calendar-cells.week.day-0..6`)과 `Today is …` 표시를 읽어 각 셀의 실제 날짜를 계산한 뒤, 각 행의 주 단위 컬럼 오버레이(`columns-overlay.column-N`)에 1/7 폭 음영 요소를 삽입합니다.
- Jira는 React로 수시로 재렌더링하지만 `MutationObserver`가 감지해 멱등하게 다시 적용합니다.
- **주(Weeks) 단위 보기에서만** 동작합니다. 월/분기 보기에는 요일 셀이 없습니다.
- 열을 실제로 접지는 않습니다. Jira가 막대를 픽셀 단위로 배치하므로 열을 접으면 앱과 충돌합니다.
- Atlassian이 DOM을 바꾸면 `content.js` 상단의 `DAY_PREFIX` / `COL_PREFIX`만 수정하면 됩니다.

## 공휴일 데이터

공휴일 달력은 `holidays.js`, UI 문자열은 `locales.js`에 있습니다. 정부가 아직 공식 확정하지 않은 날짜(중국 2027~2028 국무원 공지, 인도 2027~2028 DoPT 목록, 달 관측에 따라 바뀌는 이슬람 명절)는 휴일 이름에 *잠정(暂定/अनुमानित)*으로 표시되어 있으니 공식 발표를 확인해 *사용자 지정 휴일*이나 Pull Request로 조정해 주세요.
