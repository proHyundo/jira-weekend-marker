# Changelog

## [1.1.0] - 2026-09-08

### Added
- **Country selection**: South Korea, United States, China, India. The default is detected from the browser language (`ko`→KR, `zh`→CN, `hi`/`*-IN`→IN, otherwise US; US when the language cannot be read) and can be changed in the popup.
- **Localized UI** (popup + tooltips) in English, Korean, Chinese and Hindi; the language follows the selected country and can be overridden.
- **Holiday calendars through 2028** in `holidays.js`:
  - KR: statutory holidays incl. substitute holidays, the 2026 additions (Labor Day 5/1, Constitution Day 7/17) and the 2028 general election day.
  - US: federal holidays generated by rule (observed-day shifting included).
  - CN: State Council schedules for 2025–2026 incl. adjusted working weekends (调休, shown with a dashed underline and not shaded); 2027–2028 provisional.
  - IN: DoPT gazetted holidays for 2025–2026; 2027–2028 provisional.
- Store listing localized via `_locales` (en, ko, zh_CN, hi).
- Cross-browser packaging: `build.sh`, Safari converter script (`safari/build-safari.sh`) and a GitHub Actions release workflow that publishes Chrome/Edge and Safari packages.
- README in English with a full Korean translation.

### Changed
- Setting `useKrHolidays` renamed to `useHolidays` (migrated automatically).
- Extension API access now falls back from `chrome.*` to `browser.*` and from `storage.sync` to `storage.local` for Safari/Firefox compatibility.
